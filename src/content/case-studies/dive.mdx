## Context

Dive is a recreational scuba-planning client project that combines trip-planning features with a machine-learning safety profile and recommendations.

## Ownership

Mohamed owned and implemented the project end to end. His work covered the Android application, Python safety-classification component, API integration, Firebase services, maps and location features, and the delivered planning experience.

## Constraints

The application brings together diver inputs, planning data, safety classification, cloud data, and location services. Those capabilities needed to remain one coherent mobile workflow rather than separate technical demonstrations.

## Implementation

The Android client uses Java, Retrofit, and Gson for service communication. Firebase provides authentication, realtime data, and storage. Google Maps, Location, and Places support planning context, while the Python classifier supplies the safety-profile behavior.

## Outcome

The delivered client project combines dive planning, safety classification, recommendations, account and data services, and location-aware mobile features in one application.

## Reflection

Owning the full project made the boundaries between model behavior, service contracts, and mobile experience visible. The useful result was the integrated planner, not any one library in isolation.
